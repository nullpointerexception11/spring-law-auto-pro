# Dava (Matter) Oluşturma Kuralları

1. **Benzersizlik Kontrolü:** Aynı "Esas/Referans Numarasına" sahip birden fazla aktif dava açılamaz.
2. **Kabul Edilen Formatlar:** Esas numaraları genellikle "YYYY/NNN E." formatında olmalıdır (Örn: 2024/452 E.).
3. **Zorunlu Alanlar:** Bir dava oluşturulurken Başlık (Title) asla boş geçilemez.
4. **Zaman Damgası:** Davalar sisteme eklendiğinde açılış tarihi (opened_at) otomatik olarak sistem tarafından atanmalıdır.

*Bu kurallar yapay zeka asistanı tarafından dava açılmadan önce mutlaka dikkate alınmalıdır.*
