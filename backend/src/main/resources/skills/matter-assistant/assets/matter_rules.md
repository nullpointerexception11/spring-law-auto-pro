# Dava (Matter) Oluşturma Kuralları

1. **Zorunlu Alanlar:** Bir dava oluşturulurken Başlık (Title) asla boş geçilemez. Esas numarası (Reference Number) başlangıçta zorunlu değildir.
2. **Zaman Damgası:** Davalar sisteme eklendiğinde açılış tarihi (opened_at) otomatik olarak sistem tarafından atanmalıdır.

*Bu kurallar yapay zeka asistanı tarafından dava açılmadan önce mutlaka dikkate alınmalıdır.*
